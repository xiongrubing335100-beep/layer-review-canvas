# PNG 精修页面内大图编辑模式设计

## 1. 目标

为工作台 PNG 二次编辑区增加不遮挡图像的放大入口，让用户在保持右侧钢笔工具和修改目标输入可见的情况下，以更大的等比例预览绘制精修路径。

核心原则：

> 放大只改变工作台预览布局，不改变 PNG 像素、宽高比、精修路径坐标或编辑状态。

## 2. 用户交互

- PNG 结果进入“编辑结果”状态后，在结果预览画面之外显示“放大编辑”图标按钮。
- 按钮属于结果编辑工具区，不能绝对定位在图片之上，也不能遮挡钢笔可操作区域。
- 点击后进入页面内大图编辑模式；按钮变为“还原预览”。
- 再次点击或按 `Esc` 退出大图编辑模式。
- 右侧拆分要求、钢笔工具、修改目标和发送操作继续可见，不使用独立新窗口。
- 放大与还原不应结束编辑、取消草稿或清除已有路径。

## 3. 布局

- 大图模式扩大中间 PNG 结果编辑区域的可用宽度和高度。
- 结果预览按视口可用高度设置上限，并允许中心区域滚动，不让页面工具栏覆盖图像。
- 右侧操作面板维持现有布局和可操作性。
- 小尺寸窗口下允许预览区内部滚动，但图片仍必须完整等比例展示。
- 放大按钮位于预览下方的独立工具行，和图片边界保持明确间距。

## 4. 图像显示合同

- 使用当前成功 PNG 的实际像素宽高计算 `aspect-ratio`。
- 图片使用 `object-fit: contain`，不得使用会填满容器并裁切的 `cover`。
- 不得分别指定会改变比例的固定宽度和固定高度。
- 放大模式只增加 CSS 显示尺寸，不改写 PNG 文件、`sourceSize`、`canvasSize` 或最终输出尺寸。
- 放大、缩小前后，同一归一化钢笔坐标必须落在同一图像像素位置。

## 5. 钢笔编辑状态

- 放大与还原复用同一个 `PenPathOverlay` 实例和同一个 `resultEditState`。
- 必须保留：闭合路径、未闭合草稿、当前选中锚点、手柄、路径角色、撤销/重做历史和反馈令牌。
- 不允许通过复制路径数据到另一个弹层编辑器实现放大，避免双状态和坐标回传误差。
- 指针坐标继续相对实际预览元素归一化，布局变化后无需迁移路径数据。

## 6. 状态生命周期

- 新增仅用于显示的布尔状态，例如 `resultPreviewExpanded`。
- 退出“编辑结果”、切换拆分图层、切换当前成功 PNG 或关闭当前项目时，放大状态恢复为关闭。
- `Esc` 优先关闭大图模式；没有打开大图模式时才沿用现有其他退出行为。
- 任务提交、排队、成功或失败不应因为放大状态改变精修数据。

## 7. 可访问性

- 按钮必须有随状态变化的 `aria-label`：`放大 PNG 编辑预览` / `还原 PNG 编辑预览`。
- 使用 `aria-pressed` 表达当前大图状态。
- 键盘用户能够聚焦按钮并用 Enter/Space 切换。
- 大图模式不能破坏钢笔覆盖层现有的键盘焦点、删除、撤销和重做快捷键。

## 8. 验收标准

- PNG 编辑状态下可以看到位于图片外的放大按钮。
- 点击后图片明显变大，且右侧操作区仍可使用。
- 横向或纵向图片都保持原始宽高比，没有拉伸、压缩或裁切。
- 放大前绘制的路径在放大后位置不变，并可继续编辑；还原后仍然保留。
- `Esc` 和还原按钮都能退出大图模式。
- 退出 PNG 编辑或切换图层后不会把大图状态带到下一次编辑。
- 现有 PNG 版本展示、下载、发送、排队与结果回传行为不回归。

## 9. 非目标

- 不增加全屏弹窗、浏览器新窗口或第二套钢笔编辑器。
- 不修改 PNG 二次编辑的 ROI、ImageGen、Alpha 合成或版本化规则。
- 不改变普通框选预览现有的大图模式。
