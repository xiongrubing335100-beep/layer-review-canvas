# PNG 二次编辑：提示词与钢笔路径使用规范

## 1. 适用范围

本规范适用于 Imvia Layer 工作台中已经产出透明 PNG 后的二次编辑。目标是在不破坏原 PNG 尺寸、透明结构和未标注内容的前提下，完成局部补全、局部删除、边缘修复和对象保留。

PNG 二次编辑遵循一条基本原则：

> 钢笔路径负责说明“在哪里、允许做什么”，提示词负责说明“目标应当变成什么样”。

不要依靠提示词解释路径范围，也不要依靠路径猜测设计意图。

## 2. 用户只需要完成的三件事

1. 选择正确的钢笔工具。
2. 用闭合路径准确标出目标区域。
3. 用一句简短、明确的文字说明希望得到的结果。

尺寸、坐标、透明通道、标准画布和路径外像素锁定由工作台自动处理，不需要写进提示词。

## 3. 三种钢笔的正式含义

### 3.1 边界钢笔：限定局部修复范围

适用于补全残缺对象、修复边缘、替换小范围内容或调整局部材质。

- 闭合路径内部是允许生成式修改的区域。
- 闭合路径外部保持原 PNG 像素不变。
- 它不表示“删除路径外内容”。
- 路径应紧贴目标，并包含需要补出的缺失区域。
- 一个独立对象使用一条独立路径，不要用一条大路径同时包围多个无关对象。

示例：修复两个残缺金币时，应分别给两个金币画两条边界路径，而不是把整个轮盘和人物一起框住。

### 3.2 排除钢笔：删除为透明

适用于删除多余物体、残留背景、脏边、文字或不需要的装饰。

- 闭合路径内部会被确定性地设置为透明。
- 删除行为由本地 Alpha 处理完成，不依赖 ImageGen 理解“去掉”或“删除”。
- 路径外部保持不变。
- 如果删除后需要补全被遮挡的背景，应另外使用边界钢笔标出补全区域，并在提示词中说明补全内容。

### 3.3 保留钢笔：保护原始像素

适用于保护人物脸部、Logo、文字、产品主体或其他绝对不能变化的内容。

- 路径内部直接保留基准 PNG 的原始 RGBA 像素。
- 如果它与修复或排除路径重叠，保留路径拥有最高优先级，最终恢复基准 PNG 的原始 RGBA。
- 保留钢笔不是复制工具，也不会自动删除路径外内容。

## 4. “只保留框内、框外删除”的正确用法

“只保留框内”属于画布级操作，不属于普通边界路径的隐含含义。

正确流程：

1. 使用边界钢笔画出需要保留的完整主体轮廓。
2. 开启工作台的“仅保留路径内，路径外透明”操作。
3. 如需修复主体内部的残缺区域，再为每个残缺对象补充独立的边界路径。
4. 提示词只描述需要补全的内容，不再重复“框外删除”。

如果没有开启“仅保留路径内”，边界路径外部必须保持原样。

## 5. 路径绘制标准

### 5.1 必须满足

- 路径必须闭合。
- 至少包含三个不同锚点。
- 路径不能自相交。
- 所有锚点必须位于 PNG 像素画布内。
- 路径应覆盖完整的待修改对象以及合理的缺失补全空间。
- 不同对象使用不同路径。

### 5.2 推荐留白

- 普通边缘修复：在目标外保留约目标尺寸的 3%–8%。
- 阴影、光晕或半透明边缘：适当扩大到 8%–15%。
- 不要把路径贴死在残缺断面上，否则模型没有足够空间补全结构。
- 不要为了“保险”框住整张画面；路径越大，生成式重绘和比例漂移风险越高。

### 5.3 大范围路径警告

- 局部修复路径覆盖画布超过 40% 时，工作台应提示范围可能过大。
- 覆盖超过 70% 时，默认阻止发送，除非用户明确选择“整图编辑”。
- “整图编辑”属于高风险模式，可能改变构图、比例和对象位置。

## 6. 提示词标准结构

推荐按以下顺序书写：

> 修改对象 + 修改动作 + 目标状态 + 必须保持 + 禁止变化

### 6.1 标准模板

```text
仅处理已标注的【对象】。
将其【修改动作】，达到【目标状态】。
保持原有【位置、大小、角度、材质、光影】。
不得修改【其他对象或结构】。
```

其中“仅处理已标注区域、路径外像素锁定、保持原尺寸和透明 PNG”等技术约束由系统自动补充，用户不需要重复输入。

### 6.2 局部补全模板

```text
补全已标注的两个残缺金币，使其成为结构完整的圆形金币。
保持金币原位置、大小、角度、材质和光影。
不要移动或重绘轮盘、人物及其他金币。
```

### 6.3 删除并补背景模板

```text
删除排除路径内的装饰物。
在边界路径内补全其后方原有背景纹理和光影。
保持周围主体、颜色和透视关系不变。
```

### 6.4 边缘修复模板

```text
修复已标注主体的缺口和锯齿边缘。
延续现有轮廓、描边、材质和光影，不改变主体形状与比例。
```

### 6.5 文字或 Logo 修复模板

```text
仅修复已标注文字的缺失笔画，保持原文字内容、字形、描边和排列。
不得改字、重新排版或改变文字比例。
```

文字和 Logo 的 RGB 应优先锁定原图；如仅需透明化，不应让 ImageGen 重绘最终字形。

## 7. 不推荐的提示词及改写方式

### 7.1 指代不清

不推荐：

```text
把这里修一下，旁边两个也补好。
```

推荐：先分别给两个目标画路径，再写：

```text
补全两个已标注金币的缺失部分，保持各自原位置、大小和透视。
```

### 7.2 把路径语义写进提示词

不推荐：

```text
保留框内，框外全部删除，然后修复里面的东西。
```

推荐：用“仅保留路径内”操作处理框外透明，再写：

```text
补全已标注金币的缺失结构，保持其材质和光影。
```

### 7.3 同时提出互相冲突的要求

不推荐：

```text
整体更饱满，但所有元素位置和比例完全不变。
```

推荐：明确局部对象和允许变化的属性：

```text
仅增强已标注金币表面的高光和立体感，不改变轮廓、位置和大小。
```

### 7.4 一条路径承担多个任务

不推荐：用一条覆盖整张 PNG 的路径，同时要求删除背景、修复金币、移动人物和调整轮盘。

推荐：把任务拆成独立操作；删除使用排除路径，局部补全使用边界路径，保护对象使用保留路径。一次任务只做一种主要视觉意图。

## 8. 提交前检查清单

发送调整前确认：

- 当前显示的是希望继续编辑的成功 PNG 版本。
- 每条路径都已闭合。
- 每个待修复对象都有独立路径。
- 缺失部分也位于边界路径覆盖范围内。
- 删除区域使用排除钢笔，而不是只写“删除”。
- 需要保护的内容已使用保留钢笔。
- “仅保留框内”已通过显式操作开启，而不是只写在提示词中。
- 提示词只描述目标结果，没有使用“这里、那里、旁边”等模糊指代。
- 没有无意中选择整图编辑。

## 9. 工作台自动承担的责任

工作台必须自动完成以下内容，用户无需写进提示词：

- 读取当前成功 PNG 的实际像素尺寸。
- 原 PNG 按 1:1 放入标准画布，禁止非等比缩放。
- 路径外 RGBA 像素逐像素锁定。
- 将每条修复路径转换为独立局部 ROI。
- 自动生成完整执行提示词和禁止项。
- 确定性处理排除路径和“仅保留路径内”的 Alpha。
- 保持最终 PNG 与基准 PNG 像素宽高一致。
- 失败、排队或无效结果不得替换当前成功 PNG。
