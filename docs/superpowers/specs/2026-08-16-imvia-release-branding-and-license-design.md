## 3. README 与安装说明

仓库根目录新增 `README.md`，作为 GitHub 首页文档。应用目录内的详细 README 同步品牌、许可和链接，避免两份说明互相矛盾。

根 README 至少包含：

- 项目定位与主要能力；
- macOS 与 Windows 的前置条件；
- Git 克隆安装方式；
- ZIP 下载后的安装方式；
- 正确的应用子目录进入命令；
- 唯一安装命令 `npm run setup`；

- 插件更新方式；

- 许可与商业授权入口；

```sh

cd imvia-layer-review-canvas/imvia-ui-layer-review-canvas
npm run setup
```

Windows PowerShell 与 macOS Terminal 均使用同一套 Node 命令；Python 探测继续由现有安装器按平台处理。

## 4. 许可设计

现有 MIT License 允许自由商用，与用户要求冲突，因此正式发布前必须替换为自定义的 Imvia Layer Personal & Commercial License。README 不再称项目为 MIT 开源项目，而使用“源代码可见”或“source-available”表述。

### 4.1 免费权限

个人可以为学习、研究、评估和不产生直接或间接收入的个人项目免费使用、复制和修改项目。

### 4.2 商业使用

下列场景需要在使用前取得作者书面付费授权：

- 企业、组织或商业团队的内部使用；
- 客户项目、外包、咨询或付费交付；
- 付费产品、SaaS、订阅、广告、销售或其他营收活动；
- 将项目或其修改版本打包、集成或分发到商业产品；
- 任何以盈利、融资或商业运营为目的的使用。

商业授权默认仍需保留作者和版权通知；只有单独书面协议明确允许时才可移除或替换。

### 4.3 修改与非商业分发

个人非商业用途可以修改。非商业分发原版或修改版时，必须：

- 保留许可证、`NOTICE.md`、源码版权注释和构建版权 Banner；
- 清楚说明修改内容；
- 不得暗示作者为修改版本背书；
- 不得把原项目或修改版重新许可为允许商业使用的许可证。

### 4.4 第三方组件

第三方依赖、模型和素材继续遵守各自许可证。特别是 BRIA RMBG 2.0 权重仍受其自身非商业许可约束；项目商业授权不会自动授予第三方组件的商业权利。

### 4.5 免责

项目按“现状”提供，不承诺适销性、特定用途适用性或不侵权。许可文本明确说明：如需正式商业授权或法律安排，应通过作者主页联系并签订单独书面协议。

## 5. 作者署名与水印

### 5.1 工作台可见署名

在左侧栏底部加入低干扰的固定署名：

```text
开发者 · 青木
```

- “青木”链接到作者小红书主页；
- 点击在新页面打开，并包含安全的外链属性；
- 默认使用低对比度中性色，悬停和键盘聚焦时使用品牌绿色；
- 不遮挡图层列表，不随列表内容挤压或覆盖操作；
- 提供清晰的无障碍名称与键盘焦点样式。

### 5.2 仓库级署名

新增根目录 `NOTICE.md`，记录：

- 产品名称 Imvia Layer；
- 作者“青木”及主页；
- 版权年份；
- 个人/商业许可摘要；
- 第三方组件遵循各自许可证的说明。

### 5.3 元数据署名

在 `package.json`、插件清单和适用的项目元数据中加入：

- `author`: 青木；
- `homepage`: 作者小红书主页或最终 GitHub 仓库地址，按字段语义选择；
- `license`: `SEE LICENSE IN LICENSE` 或等价的自定义许可标识；
- `repository`: 最终 GitHub 仓库地址。

### 5.4 源码版权注释

只在关键入口文件增加简短、统一的版权头，避免在每个小文件重复造成噪声。覆盖范围至少包括：

- React 工作台入口；
- MCP 服务入口；
- 工作台启动与插件安装入口；
- PNG 最终处理主入口；
- 插件模板的核心入口。

统一注释示例：

```text
Imvia Layer © 2026 青木。个人非商业使用免费；商业使用需取得付费授权。
```

注释同时指向根 `LICENSE` 和 `NOTICE.md`。这些标记用于归属和取证，不宣称技术上不可删除。

### 5.5 构建版权 Banner

Vite/Rollup 构建配置为生产 JavaScript 添加可保留的版权 Banner：

```text
/*! Imvia Layer © 2026 青木 — Personal non-commercial use only; commercial license required. */
```

生产构建验证必须确认该 Banner 存在于生成的 JavaScript 中。Banner 不包含用户数据、机器标识或网络请求。

## 6. 明确不做的事情

- 不承诺代码标记在第三方恶意删除后仍必然存在。
